这一步能还原什么 / 不能还原什么

能：页面尺寸与背景、文本框（逐段逐 run 的字号/粗斜体/字体/颜色/对齐）、 矩形圆角矩形椭圆三角形等预设形状（填充/渐变/边框/虚线/旋转/翻转）、线条、 表格（行列、列宽行高、逐格文字）、组合内部坐标系的换算。

不能：图片——文本里只有位置和文件名没有像素，会画成带文件名的虚线占位框， 位置给你留着，自己贴图；真图表对象——「疑似图表」会按文本里给的柱子几何原样摆成矩形 （形状与原图一致），但那不是可编辑的 PPT 图表；阴影发光等效果暂未还原。

提示：让 AI 改内容时，让它只改引号里的文字，别动「位置:」那些行—— 改文字是安全的，改坐标就得自己核对了。

PDF 能提取什么 / 不能提取什么

能（实测，精确）：页面尺寸与旋转、每段文字的内容与坐标、字体名/字号/粗斜体/颜色、 矢量图形的路径与填充边框颜色、图片的位置尺寸与格式、绘制顺序（z 轴）、文档大纲与书签、 加密 PDF 自动解密。

能（推断，带置信度）：行合并成段落、段落归成文本块、多栏阅读顺序、页眉页脚识别、 表格行列还原、柱状图/饼图的几何还原、背景色块识别。

不能：图片本身的像素（只给位置和尺寸；exe 版可用「高保真重解析」导出图片）、 扫描件里的文字（没有文字层，需 OCR）、动画与交互。

PPT 能提取什么 / 不能提取什么

几乎全是实测值。PPTX 里存的是语义对象，不需要像 PDF 那样从几何反推： 每个形状的类型与几何、填充（纯色/渐变/图案/图片）、边框、阴影发光等效果、 逐 run 的字号字体粗斜体颜色、段落对齐行距项目符号、表格逐格格式与合并、 图表类型与全部数据系列、组合层级、z 轴顺序。

★ 版式与母版：会读取 slideLayout / slideMaster，把模板元素（logo、色条、页脚） 单独列进「版式库」只描述一次；占位符继承来的位置和字号也会解析出来并标注来源。 隐藏形状会跳过并计数，图片裁剪会给出裁剪百分比。

不能：图片像素（只给文件名与位置）、SmartArt 内部布局（降级成组合形状）、 动画与切换效果、旧版 .ppt（需先另存为 .pptx）。

注意：数据会离开这台机器吗

这个工具本身不联网，文件全程只在本机内存里处理，不上传任何地方。 但你把生成的文本粘贴给 AI 时，文本就离开了这台机器——之后怎么用是你的判断。

怎么装到公司电脑上

这个文件本身就是纯文本。在公司电脑上：打开记事本 → 把这份 HTML 的全部源码粘贴进去 → 另存为 PDF转AI文本.html（编码选 UTF-8）→ 双击用 Edge/Chrome 打开即可。不需要安装、不需要管理员权限、不需要联网。

需要 Edge / Chrome 100+（用到 DecompressionStream）。
